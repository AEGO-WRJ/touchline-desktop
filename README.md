# 看球 · Touchline Desktop

Windows 桌面足球比分卡片，显示五大联赛和欧冠赛程、比分及比赛统计。

## 下载与运行

在 [Releases](https://github.com/AEGO-WRJ/touchline-desktop/releases/latest) 下载 `Touchline.exe`，双击运行。使用 Windows 10/11 的 .NET Framework 4.x，无需安装 Python、Node.js 或注册数据账号。

升级时先退出旧卡片，再启动新版。配置保存在当前 Windows 用户的本地应用数据目录，移动或替换程序不会清空配置。

## 功能

- 英超、西甲、意甲、德甲、法甲、欧冠，统一使用北京时间。
- 赛程按开赛时间连续排列，默认显示今天起一周，支持加载更早或更晚的赛程。
- 顶部“今天”按钮定位今天的赛程。
- 多选关注球队，支持中文、英文搜索、取消关注和上下移动排序。
- 首位关注球队的队徽显示在卡片顶部；关注排序不改变比赛顺序。
- “只看关注球队”、赛事和“只看进行中”筛选可叠加。
- 点击比赛展开控球率、射门、射正、角球、犯规与关键事件，缺失值显示为 `—`。
- 比分变化提示，正确区分进球和比分回调；可选提示音。
- 可拖动、调整大小、置顶、调整透明度和收起到系统托盘。

## 本地保存

关注配置位于：

```text
%LOCALAPPDATA%\TouchlineCard\favorites.json
%LOCALAPPDATA%\TouchlineCard\favorites.json.bak
```

关注球队、关注顺序和“只看关注球队”开关在每次修改时立即写入。写入先完成临时文件，再替换目标文件；另存一份备份。主配置无法读取时尝试从备份恢复。保存失败会明确提示，不会假装保存成功。

第一次升级会从旧的 `settings.json` 自动迁移关注名单。窗口位置、大小、置顶等设置仍保存在 `settings.json`。设置窗口提供“打开配置目录”入口。

个人配置和赛程缓存仅保存在本机，不随 Git 仓库或发布包上传。

## 数据与刷新

数据来源为 [ESPN](https://www.espn.com/soccer/scoreboard) 的公开比分接口。本项目不隶属于 ESPN 或懂球帝。

赛中每 30 秒检查比分，其余每 2 分钟检查。未来赛程缓存 15 分钟，较早日期缓存 6 小时。手动刷新会重新读取已加载范围。断网时保留已有缓存并标识可能过期。

刷新间隔不等于现场延迟。接口可用性、数据覆盖、赛程调整及延迟取决于数据源。电脑休眠或程序关闭后不会继续更新。球队名称优先中文，球员和球场名称可能为英文。队徽从 ESPN 的图片服务加载，未随项目分发图片文件。

## 构建与测试

在 Windows PowerShell 中进入仓库目录：

```powershell
.\test.ps1
.\build.ps1
```

构建结果位于 `dist\Touchline.exe`。脚本使用 Windows 自带 .NET Framework C# 编译器，无第三方 NuGet 依赖。

测试覆盖北京时间日期边界、多日赛程、主客队匹配、组合筛选、关注排序、首位队徽、比分通知、VAR 更正，以及实际文件写入、重读、旧配置迁移、备份恢复和写入失败。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `App.cs` | WPF 桌面界面和交互 |
| `Core.cs` | 比赛解析、筛选、关注名单与比分变化 |
| `FavoriteStore.cs` | 本地关注配置、迁移、备份和恢复 |
| `Feed.cs` | 数据读取、并发限制和赛程缓存 |
| `TeamDirectory.cs` / `teams.json` | 球队目录与队徽地址 |
| `Names.cs` | 球队中文名 |
| `Tests.cs` | 无网络依赖的自动测试 |

测试响应样例只保留验证所需的公开赛事字段。球队目录和译名需要随赛季变化维护。
